# 07 答辩演示指南（3-5 分钟）

## 演示前

1. 执行 `init_demo.bat`，再执行 `start.bat`。
2. 浏览器打开 `http://127.0.0.1:8000/`。
3. 准备两个浏览器窗口或无痕窗口，分别用于 `admin` 与 `user`。

## 操作顺序

1. 用 `admin / Demo@123456` 登录，展示 Dashboard 的 8 个真实卡片和四组图表。
2. 打开果园、地块、设备和实时数据，说明已有 3 个果园、12 个地块、24 个设备和历史趋势。
3. 在终端运行 `python manage.py simulate_iot --count 10`，刷新 Dashboard，说明今日数据量变化。
4. 运行 `python manage.py simulate_iot --count 1 --abnormal`，在实时数据筛选“异常”，展示湿度 150 被保存并标记原因。
5. 打开敏感字段字典和识别记录，展示联系人、手机号、设备编号、位置、坐标和采集时间的分类分级。
6. 管理员打开实时数据或安全 API，看到原始设备编号和时间。
7. 用 `user / Demo@123456` 登录相同页面，展示设备编号 `****`、采集时间 `**:**:**`，再打开 JSON API 证明后端接口同样不泄露。
8. 在普通用户安全导出中心申请超过阈值的数据；状态进入 PENDING，同时生成审计和风险事件。
9. 用 `security / Demo@123456` 登录，打开安全导出中心审批；生成后的 CSV 包含 EXPORT_ID、USER、EXPORT_TIME，敏感字段仍脱敏。
10. 打开安全告警，选择待处理告警，展示可解释分项，填写“已确认异常批量导出，限制用户操作”，状态改为 RESOLVED。
11. 返回 Dashboard，展示风险事件、告警、脱敏次数等来自真实业务变化。

## 越权演示

用 `orchard_admin` 直接修改 URL 中设备 ID 为其他果园设备，系统返回 403；随后在审计日志和风险事件中查看越权证据。不要在正式答辩时反复触发查询限频，以免影响后续操作。
