# UI 设计系统

## 设计方向

系统定位为智慧农业数据安全控制台，采用浅色工作区配合深绿色导航。视觉重点是“可信、克制、可追溯”，避免普通 CRUD 模板的廉价感，同时保证答辩投影环境下的可读性。

## 颜色 Token

- 主色：`#176B59`，用于主按钮、活动导航和关键链接。
- 深色：`#0D2E27`，用于侧边栏和高对比信息容器。
- 画布：`#F4F7F5`；表面：`#FFFFFF`；边框：`#DFE8E3`。
- 成功/在线/低风险：`#16856F`。
- 提醒/中风险：`#D99427`。
- 失败/异常/高风险：`#C84F4A`。
- 严重风险/阻止：`#8F2C36`，必须同时显示文字，不仅依赖颜色。
- 图表辅助色：蓝 `#3B82C4`、紫 `#8B6DB7`、青 `#2995A3`。

## 字体与层级

- 字体栈：Segoe UI、PingFang SC、Microsoft YaHei。
- 页面标题 26px/700，组件标题 16px/700，正文 13-15px，辅助说明 10-12px。
- 统计数字 27px/800，使用等宽数字表现。
- 设备编号、导出 ID、哈希使用 Cascadia Code/Consolas。

## 间距、圆角和阴影

- 间距采用 4/8/12/16/20/24/28/32/48 序列。
- 小圆角 8px，中圆角 12px，大圆角 18px，状态徽标使用胶囊圆角。
- 卡片只使用轻边框和低强度阴影；登录卡片及移动侧栏可使用大阴影。

## 组件规范

- 侧边栏宽 252px，按“工作台、资产与数据、数据安全、导出与运维”分组。
- 顶栏显示系统健康、时间、角色、用户和退出操作。
- 表格表头使用浅色底和小号字，行悬停只做轻微底色变化。
- 表单必须显示标签、必填标识、帮助文字和服务端错误。
- 风险、设备、审批和告警状态统一使用 `status-badge`，颜色与文本并存。
- 危险或高影响操作需要明确按钮文本和服务端二次权限检查。

## 图表规范

- 传感器折线图明确单位和时间范围；温度、湿度、墒情保持固定色彩。
- 状态分布使用环形图，分类分级使用柱状图，风险/告警使用组合趋势图。
- 数据为空时保留图表容器，不伪造曲线；Dashboard 统计只读取 ORM 聚合结果。
- 支持今日、近 7 天、近 30 天时间范围。

## 响应式与无障碍

- 1180px 以下减少统计卡和图表列数；860px 以下侧边栏抽屉化；620px 以下单列。
- 提供跳过导航链接、表格表头、表单标签、图表替代说明和清晰焦点状态。
- 遵循 `prefers-reduced-motion`，状态信息不只依赖颜色。
