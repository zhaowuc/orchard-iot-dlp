# 基于 Python 的果园物联网数据防泄漏与脱敏系统：实施计划

## 1. 工程架构

采用 Django 5.2 LTS 单体分层架构，服务端渲染 Django Template，前端使用本地 CSS、Vanilla JavaScript 与 ECharts。请求经过认证、角色/属性访问控制、业务服务与统一审计后通过 Django ORM 访问 SQLite；模型和查询保持数据库无关，便于切换 MySQL。IoT 数据通过带设备令牌的 HTTP API 接入，MQTT 作为可选适配器；无硬件时由管理命令生成连续趋势数据。

核心分层：

- 表现层：Template、表单、JSON API、CSV 导出。
- 应用层：视图只完成参数校验、调用服务、组装响应。
- 领域服务：数据校验、敏感识别、动态脱敏、访问控制、审计、风险评分、导出安全。
- 数据层：Django ORM、事务、索引与约束。
- 运维层：环境变量、应用日志、启动脚本、Demo 初始化、自动化测试。

## 2. Django Apps 划分

- `accounts`：自定义用户、角色、果园授权、登录失败审计、用户和角色管理。
- `orchards`：果园、地块、网关、设备、数据源及资产页面。
- `iot`：传感器读数、HTTP 接入、校验、异常标记、模拟器、MQTT 适配。
- `sensitive`：字段字典、识别规则、分类分级、识别记录。
- `masking`：脱敏规则、动态脱敏服务、预览与命中记录。
- `dlp`：访问策略、查询监控、限频、导出申请、审批、追踪与安全下载。
- `audit`：统一审计、行为基线、风险事件、安全告警、告警处置。
- `dashboard`：实时统计卡片、趋势图表、最近事件与系统参数。

## 3. 数据库关系

- User 通过多对多关系关联 Role，通过多对多关系获得 Orchard 数据范围。
- Orchard 1:N Plot、Gateway、Device、DataSource、SensorReading。
- Plot、Gateway 关联 Device；Device 1:N SensorReading。
- SensitiveFieldDefinition、SensitiveRule 产生 SensitiveDetectionRecord。
- MaskingRule 产生 MaskingRecord；记录用户、场景、字段类型和规则。
- AccessPolicy 按角色、果园、地块、设备、敏感等级和操作判定。
- QueryMonitor、ExportRequest、ExportRecord 关联用户和数据范围。
- AuditLog 为 RiskEvent 提供证据；RiskEvent 达阈值生成 SecurityAlert。
- SystemConfig 集中保存限频、导出、告警和设备离线阈值。

## 4. 用户角色

- `SUPER_ADMIN`：全局管理、原文权限、所有安全与系统配置。
- `SECURITY_ADMIN`：安全规则、审计、风险、告警和导出审批；默认不维护果园业务资产。
- `ORCHARD_ADMIN`：仅管理已授权果园及其地块、设备和数据，原文按策略决定。
- `NORMAL_USER`：已授权范围只读，敏感字段默认动态脱敏，大规模或高敏导出进入审批/拒绝。

所有权限由后端服务、查询集过滤和对象级检查强制执行；模板隐藏按钮只作为交互优化。

## 5. 核心业务闭环

1. 设备令牌认证后提交数据。
2. 校验设备、时间、重复性、类型和合理范围；异常数据保留并标记。
3. 敏感识别服务按字段名、正则和业务标签生成分类分级记录。
4. 查询、API 和导出统一调用动态脱敏服务，数据库始终保存原值。
5. 访问控制服务校验角色和果园/地块/设备范围，限频服务记录查询行为。
6. 导出服务再次校验权限和脱敏策略，按规模和敏感级别直出或进入审批，并写入追踪元数据和文件哈希。
7. 统一审计记录关键操作，风险服务根据可解释因素计算 0-100 分。
8. 达阈值生成安全告警，安全管理员处置并再次形成审计记录。
9. Dashboard 从真实业务表聚合统计，展示业务趋势和安全状态变化。

## 7. 验收基线

- `manage.py check`、迁移检查、完整测试通过。
- 四角色权限及 IDOR/直接 URL/导出下载隔离通过。
- IoT 正常和异常数据均真实入库，模拟器可驱动 Dashboard 变化。
- 列表、详情、API、CSV 四个入口对普通用户均不泄露原文。
- 高频查询、大规模导出、越权访问可生成审计、风险事件和告警。
- 关键列表具备搜索、筛选、分页；Dashboard 数据来自 ORM 聚合。
- Windows/Linux 初始化与启动脚本可用，文档支持 3-5 分钟答辩演示。
