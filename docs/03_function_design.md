# 03 功能设计

## 六大模块 / 二十四个子功能

1. 数据采集与资产管理：设备登记、HTTP/MQTT 接入、数据校验、异常标记。
2. 敏感识别与分类分级：字段字典、规则识别、等级设置、识别记录。
3. 动态数据脱敏：策略配置、掩码/泛化、Token/哈希/随机替换、脱敏预览。
4. 数据防泄漏：角色与属性控制、查询限频、导出审批/追踪、异常行为拦截。
5. 安全审计与风险预警：统一操作日志、规则型行为基线、可解释风险评分、告警处置。
6. 统计展示与系统运维：安全看板、业务/安全趋势、报表下载、用户/角色/参数维护。

所有页面操作进入数据库和业务服务。Dashboard 不包含写死统计；模拟器和 HTTP API 能驱动卡片、图表、异常数据和审计记录变化。
