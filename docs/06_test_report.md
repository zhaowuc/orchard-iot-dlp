# 06 测试报告

## 环境

- Windows 11，Python 3.12.10
- Django 5.2.15 LTS，SQLite 3.49.1
- 测试命令：`.venv\Scripts\python.exe manage.py test`

## 结果

最终独立验收后共 82 项自动化测试，全部通过；其中原有业务测试 38 项，新增独立攻击与回归测试 44 项。

覆盖范围：

- 登录成功、失败、禁用用户、连续失败风险事件。
- 超级管理员、安全管理员、果园管理员、普通用户的权限差异。
- 果园管理员只能查看授权果园；修改其他果园对象 ID 返回 403 并产生审计/风险。
- IoT 正常数据保存、湿度 150 异常标记、未知设备、错误令牌、重复数据保留与模拟器。
- 手机号、设备编号规则识别和四级分类。
- 管理员原文、普通用户手机号/设备号/坐标/时间脱敏。
- JSON API 和 CSV 导出不向普通用户泄露原始设备编号。
- 查询窗口超过阈值后阻止并创建 RiskEvent。
- 小规模导出直出、大规模导出审批、他人 Export ID 下载 403。
- AuditService 请求上下文、82 分风险分项、阈值自动告警、告警处置及二次审计。
- Dashboard 统计与数据库数量一致，未登录访问重定向。

验收命令还包括 `manage.py check` 和 `manage.py makemigrations --check`。
